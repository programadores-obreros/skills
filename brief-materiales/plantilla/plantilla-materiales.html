Cómo usar esta plantilla

  1. Editar el contenido: abrí este archivo con un editor de texto (o pedile a tu IA que lo edite) y cambiá solo el bloque const MATERIAL = { ... } que está antes de las piezas. Todo el diseño se actualiza solo.
  2. Imprimir la hoja A6 (mariposas): abrí este archivo en el navegador, Ctrl+P → Destino "Guardar como PDF" → Papel A4 → Márgenes "Ninguno" → Escala 100%. Salen 2 páginas: la hoja a color y la hoja en blanco y negro para fotocopia. Cortá primero al medio y después cada mitad, siguiendo la línea punteada.
  3. Guardar el posteo o la historia para redes: cada pieza tiene su tamaño exacto en píxeles (1080×1080 o 1080×1920). La forma más simple es: click derecho sobre la pieza → "Inspeccionar" → activar la vista de dispositivo móvil (ícono de celular) → poner ese ancho y alto exactos → sacar una captura de pantalla con la herramienta de captura del navegador o del sistema operativo, recortando solo esa pieza.
  4. Revisá el texto letra por letra antes de publicar o imprimir.
Si le pasaste este archivo a una IA para que lo complete: solo tiene que cambiar el bloque MATERIAL, eligiendo la variante (tipografico / bloque / foto / consigna) que mejor le quede a este contenido en particular. Nunca debe rediseñar la estructura, achicar el QR por debajo de 20×20 mm, ni bajar el cuerpo de 9 pt o el pie/redes/fecha de 7 pt.
