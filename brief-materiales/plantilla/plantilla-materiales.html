Cómo usar esta plantilla

  1. Editar el contenido: abrí este archivo con un editor de texto (o pedile a tu IA que lo edite) y cambiá solo el bloque JSON <script type="application/json" id="material"> que está antes de las piezas. Todo el diseño se actualiza solo. Si le pasaste este archivo a una IA para completarlo, guardá el resultado DENTRO de esta misma carpeta "plantilla/" para que los logos sigan cargando.
  2. Posteo o historia (redes): tocá el botón "Ver en tamaño real" de esa pieza — se abre sola en una pestaña nueva, del tamaño exacto en píxeles. Sacale una captura de pantalla completa de esa pestaña con la herramienta de tu sistema operativo o navegador.
  3. Piezas para imprimir (mariposas A6, A5, A4): tocá el botón "Imprimir / Guardar PDF" de esa hoja — se abre el diálogo de impresión de tu navegador con solo esa hoja. Elegí "Guardar como PDF" o mandala directo a la impresora.
  4. Revisá el texto letra por letra antes de publicar o imprimir.
Si le pasaste este archivo a una IA para que lo complete: solo tiene que cambiar el bloque JSON, eligiendo la variante (tipografico / bloque / foto / consigna) que mejor le quede a este contenido en particular. Nunca debe rediseñar la estructura ni el CSS, achicar el QR por debajo de 20×20 mm, ni bajar el cuerpo de 9 pt (A6) / 10 pt (A5/A4) o el pie/redes/fecha de 7 pt.
